# スカイライン・テクノロジーズ 企業サイト

ソフトウェア開発会社「スカイライン・テクノロジーズ」の企業サイト（1ページ構成）です。
HTML・CSS・JavaScript を `index.html` 1ファイルにまとめているため、ビルドやインストールは不要です。

## ページ構成

| セクション | 内容 |
|---|---|
| トップ | キャッチコピーと、開発相談・実績へのリンク |
| 事業内容 | 受託開発／SaaSプロダクト／クラウド基盤・運用／技術顧問・内製化支援 |
| 実績 | これまでに開発したシステムの紹介 |
| 進め方 | 現地調査 → 設計と試作 → 開発 → 運用と改善 |
| 会社概要 | 会社情報 |
| 採用 | 採用情報と問い合わせへのリンク |
| お問い合わせ | 入力チェック付きの問い合わせフォーム |

> **補足:** お問い合わせフォームはデモです。入力内容をブラウザ上で確認するだけで、実際には送信されません。

## ファイル構成

```
company-site/
├── index.html   # サイト本体（HTML・CSS・JavaScript）
└── README.md
```

## ブラウザで開く手順

### 方法1：ファイルを直接開く

1. Finder で `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。既定のブラウザでサイトが表示されます。

ターミナルからは、次のコマンドでも開けます（macOS）。

```sh
cd ~/dev/onodevlog/company-site
open index.html
```

### 方法2：ローカルサーバーで開く

本番に近い環境で確認したいときは、Mac に標準で入っている Python で簡易サーバーを起動します。

```sh
cd ~/dev/onodevlog/company-site
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。サーバーを止めるときは、ターミナルで `Ctrl + C` を押します。

> **注意:** フォントは Google Fonts から読み込みます。インターネットに接続していないと、代わりのフォントで表示されます。
